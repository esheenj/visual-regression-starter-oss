Compare fictional pixels yourself.

This is a browser-only learning tool using the same ASCII P3 comparison engine as the command-line MVP. Edit two tiny, fabricated images, choose limits, and inspect the difference. No uploads, accounts, remote assets or persistent storage.

Educational only. Not a screenshot capture service, visual accessibility audit, security control or proof that a design change is correct. A high tolerance can hide meaningful changes.
